# Creatividad Docente

**Planea mejor. Enseña mejor.**

Plataforma web para la creación de planeaciones docentes enfocadas en la Nueva Escuela Mexicana (NEM).

## Estructura

- `index.html` — interfaz principal.
- `css/styles.css` — estilos.
- `js/app.js` — lógica de la aplicación.
- `curriculum/` — bases curriculares por fase.
- `tools/` — herramientas de desarrollo.

## Versión

Versión funcional con el módulo **Nueva planeación**, selección de grado, fase, campo formativo, contenido, PDA separados y ejes articuladores.
