# Creatividad Docente

**Planea mejor. Enseña mejor.**

Plataforma web para la creación de planeaciones docentes enfocadas en la Nueva Escuela Mexicana (NEM).

## Versión actual

Incluye el módulo **Nueva planeación** con selección de grado, fase, campo formativo, contenido, PDA separados y ejes articuladores.
